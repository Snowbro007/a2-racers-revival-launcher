# A2 Racers Revival

Een onafhankelijke fanlauncher voor de Nederlandse A2 Racer-games op Windows 11 x64.

**[Download de Windows-launcher](https://github.com/Snowbro007/a2-racers-revival-launcher/releases/latest)** · Beta 0.1.0-beta.1

## Installeren

1. Download de ZIP en pak hem volledig uit in een schrijfbare map met minstens 4 GB vrije ruimte.
2. Open **Launcher.cmd**. De eerste start vereist internet en haalt gecontroleerde componenten bij hun officiële leveranciers op. Je hoeft Python niet zelf te installeren.
3. Kies je game en koppel je eigen volledige, ondersteunde Nederlandse gamemap. Een eigen gamearchief importeren kan waar die keuze wordt aangeboden.
4. Kies **Aanbevolen** en **Spelen**. Voor deel III: kies eerst de tour en **Gamemap selecteren**.

De launcher gebruikt afzonderlijke lokale kopieën en bewaart je oorspronkelijke bestanden. De games worden niet meegeleverd of gedownload. Bewaar een backup van `local/` bij updates: daar staan je gekoppelde games, instellingen en voortgang.

## Games en opties

| Game | Status | Opties |
| --- | --- | --- |
| A2 Racer I | Revived; lokaal speelbaar | Aanbevolen Full HD, optionele HD textures en HD-menu |
| A2 Racer II | Speelbaar | Aanbevolen Full HD; resolutie, HUD, lucht en wegzicht |
| A2 Racer III: Europa Tour | In ontwikkeling | Tour 1/2; originele weergave, compatibiliteitsproef en Full-HD-proef zonder horizon/wolken |

**Origineel · Aanbevolen · MAX** zijn beschikbaar waar ondersteund. HD blijft bij deel I optioneel en standaard uit. De uitgebreide II-HD-HUD en MAX kunnen ontbreken op een schone pc. Deel-III-proeven zijn geen bevestiging van volledige speelbaarheid. Alleen de ondersteunde Nederlandse versies worden geaccepteerd; een onvolledige of gewijzigde installatie kan worden geweigerd.
